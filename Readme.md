# ✨ Pixel Cookbook ✨

A cozy pastel pixel-art recipe website inspired by retro cooking games, nostalgic internet aesthetics, and cute pixel cafés.

## 🌸 Features

- Pixel-art themed recipe cards
- Multiple recipe pages
- Animated decorative star backgrounds
- Cozy pastel design system
- Hover animations & interactive UI
- Retro game inspired visuals
- Responsive card layouts

## 🍓 Recipes Included

- Pancakes
- Pudding
- Pizza
- Cookies
- Croissant
- Focaccia
- Spaghetti
- Shortcake

## 🛠 Built With

- HTML
- CSS
- JavaScript

## 🎀 Aesthetic Inspiration

This project is inspired by:

- Retro Nintendo cooking games
- Pixel café aesthetics
- Cozy pastel websites
- Kawaii bakery themes
